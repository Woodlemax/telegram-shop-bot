# Проверка файла перед покупкой дополнения

В `/admin` откройте дополнение → **Проверка файла**. Загрузите эталон (до 128 МБ), укажите понятное описание необходимого файла и включите «Требовать файл для покупки». Для нового товара сначала сохраните карточку. Настройка действует для любого товара магазина, в том числе модификации основной модели; внешние покупки и подписки не поддерживаются.

В карточке непроверенного товара вместо добавления в корзину появляется «Приложить файл», а под ней — ваши инструкции. Проверка проводится на сервере по SHA-256 полного содержимого, имени файла соответствовать необязательно. Только серверная Telegram-авторизация определяет пользователя. Правильный файл открывает покупку этому пользователю только для данного товара; отправка одного хэша вместо файла не принимается. Загрузки ошибочного/пустого/слишком большого файла не дают разрешения.

Эталон и пользовательские файлы потоково хешируются, их содержимое не сохраняется. В базе находятся хэш, имя, размер, версия эталона и персональные отметки проверки. Ни эталон, ни его хэш не выдаются в API магазина или админки. Пересохранение STL и любые изменения байтов меняют хэш; переименование исходного файла допустимо. Это проверка наличия исходного файла, а не подтверждение покупки у автора: человек с копией исходника также сможет пройти проверку.

Замена содержимого эталона увеличивает версию. Старые разрешения сохраняются в базе, но больше не открывают новые покупки. Повторная загрузка того же содержимого и изменение описания/имени не сбрасывают разрешения. Если дополнение уже в корзине или неоплаченном заказе, загрузить новый файл можно оттуда. Создание заказа, выпуск новой платёжной ссылки, продолжение бесплатного оформления и Stars pre-checkout проверяют текущую версию повторно. Защита находится и в транзакциях хранилища, поэтому старый экран, ручные API-запросы и смена клиента не обходят проверку.

Подтверждённые покупки и скачивание оплаченных архивов не затрагиваются. Уже выпущенный внешний счёт остаётся под управлением платёжного провайдера: замена эталона не отменяет ранее открытый счёт. Факт уже совершённой оплаты обрабатывается обычным платёжным контуром; новая проверка не удерживает оплаченный архив.

После обновления Mini App закройте и откройте её снова. Покупательские строки доступны на всех пяти языках магазина. Изменения настройки и эталона проходят только административный API; редактирование проверяет ревизию, чтобы не перезаписать одновременное изменение.
