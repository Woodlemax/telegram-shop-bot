# Развёртывание Go-бота на Railway

Разворачивается корень репозитория telegram-shop-bot из ветки railway-deploy.
Python-проект PayBot в родительской папке в эту сборку не входит.

## Сервис и постоянные данные

Railway собирает Dockerfile. Файл .railway/railway.ts описывает один экземпляр,
том /app/data и проверку /health. Переменные задаются отдельно через Railway.
Описание задаёт Deployment Overlap 0 и Draining 20 секунд.
В Settings сервиса дополнительно проверьте отключённый Serverless и
Restart Policy ON_FAILURE с 10 попытками (настроено при первом переносе).
Для работы с описанием установите Node.js 22 или новее и зависимости через npm ci,
а Railway CLI версии 5.42.1 или новее добавьте в PATH.
После изменения описания инфраструктуры проверьте railway config plan
и примените railway config apply. Не используйте устаревший railway.json.
Приложение слушает порт из PORT, локальное значение по умолчанию — 8080.
Не настраивайте cron или несколько реплик для этой SQLite-базы.

Подключите к сервису постоянный Volume с mount path /app/data.
База, очередь выдачи, каталог и права покупателей должны оставаться на этом томе.
Архивы и фотографии используют Telegram file_id; их привязки хранятся в базе.
Ежедневные SQLite-снимки также сохраняются на томе в /app/data/backups.
Снимки на том же диске полезны для отката, но не заменяют внешнюю резервную копию.

Обязательные настройки сервиса:

| Переменная | Значение |
|---|---|
| BOT_TOKEN | Существующий токен, только в Variables Railway |
| ADMIN_IDS | ID владельца из действующей конфигурации |
| APP_ENV | production |
| DB_PATH | /app/data/shop.db |
| BACKUP_DIR | /app/data/backups |
| LOCALES_DIR | /app/locales |
| RAILWAY_RUN_UID | 0 |
| LOG_LEVEL | info |
| REDIS_ADDR | 127.0.0.1:6379 для запуска без отдельного Redis |

RAILWAY_RUN_UID=0 требуется для доступа к Volume, который Railway монтирует
с владельцем root. В обычном Docker-образе остаётся пользователь app.

Redis необязателен. Без него состояния незавершённых диалогов теряются после
перезапуска, кеширование выключено и уведомления о повышении уровня лояльности
не работают. Каталог, заказы, покупки, балансы и очередь выдачи остаются в SQLite.
При необходимости добавьте Redis и его REDIS_ADDR/REDIS_PASSWORD.

## Публичная витрина

Создайте Railway domain для HTTP-порта приложения. Укажите:

- WEBAPP_URL=https://<Railway domain>/app
- SHOP_OFFER_URL=https://<Railway domain>/app/offer.html, если используете
  опубликованную в проекте оферту.
- BOT_USERNAME, SHOP_CONTACTS_TEXT, BOT_ADMIN_ONLY и STARS_ONLY_PAYMENTS
  перенесите из действующей конфигурации, сохранив настройки магазина.

Для первого запуска можно сохранить long polling: WEBHOOK_URL остаётся пустым.
Telegram не требует отдельного webhook для Stars. Другие уже подключённые
платёжные системы требуют проверки их URL возврата и уведомлений при переносе.
Если переходите на Telegram webhook, задайте WEBHOOK_URL и сильный
TELEGRAM_WEBHOOK_SECRET; это изменит маршрут доставки обновлений Telegram.

## Перенос существующей базы

1. Соберите образ и выполните тесты до отключения действующего бота.
2. Остановите прежний экземпляр перед окончательным снимком базы и запуском
   нового экземпляра с тем же BOT_TOKEN. Два poller одновременно конфликтуют.
3. Снимайте SQLite через VACUUM INTO или копируйте полностью закрытую базу;
   не копируйте один shop.db у работающей базы без учёта WAL.
4. Загрузите снимок на пустой Volume как /shop.db через railway volume files
   upload. Пути этой команды идут от корня тома, а не от /app/data.
5. Запустите сервис. Миграции применяются автоматически.
6. Проверьте /health, /app/, каталог, административные права и отсутствие
   ошибок Telegram Conflict в логах. Реальный платёж для проверки не нужен.
7. В случае неудачного запуска остановите Railway-сервис до возврата локального
   экземпляра. Не восстанавливайте старую базу поверх новых покупок.

## Обновления и цена

Обновляйте только выбранную ветку; main автоматически не изменяется.
Перед загрузкой CLI исключает локальные секреты, базу и сборочные файлы через
.gitignore и .railwayignore. Docker дополнительно исключает их из образа.
Токены не должны попадать в Git, сообщения чата или журналы команд.

Пробный кредит ограничен по времени и объёму. Для постоянной работы нужна
подписка; Hobby начинается с $5 в месяц с включёнными ресурсами на $5.
Стоимость тома и сервиса учитывается в потреблении. Настройте расходные
уведомления и лимит в Railway; достижение жёсткого лимита может остановить бота.
