# Админка PrintWing

В личном чате с ботом отправьте `/admin` и нажмите **Открыть админку**. Это отдельный Mini App по адресу `/admin/`; покупатели продолжают пользоваться `/app/`.

Доступ определяется существующим списком `ADMIN_IDS`. Сервер проверяет подпись и срок действия Telegram `initData`, затем Telegram ID при каждом чтении, сохранении и загрузке. Добавлять токен бота в браузер или вводить отдельный пароль не требуется. Открытие адреса в обычном браузере не даёт доступа к данным. При истечении сеанса закройте админку и откройте снова через команду.

## Разделы

| Раздел | Возможности |
|---|---|
| Товары | Поиск по названию/ID, создание, редактирование и удаление. Цены в рублях с предпросмотром Stars, свободная цена, покупка у автора через личный Telegram или HTTPS-страницу сайта, цена по запросу, подписки, наличие, скрытие, «Скоро ожидается», один экземпляр в корзине, модификации, группа/канал. |
| Фото | Загрузка JPG/PNG/WebP до 16 МБ, добавление HTTPS-ссылки, удаление, изменение порядка. Первое фото — обложка; до 10 фото всего. |
| Проверка файла | Эталон до 128 МБ, описание нужного файла, включение/отключение проверки и версия. Покупатель загружает оригинал перед покупкой; замена эталона не отзывает купленные архивы. |
| Архив | Загрузка ZIP до 128 МБ. Замена распространяется на все прежние покупки модели. |
| Категории | Создание, название, эмодзи, ID премиум-эмодзи, порядок и видимость. Удаление пустой категории. |
| Заказы | Фильтры, поиск по номеру заказа/Telegram ID, состав, статусы, платёж, доставка, возврат, прикрепление и отправка чека «Мой налог», экспорт CSV по датам. |
| Промокоды | Общие, для категории или списка товаров; скидка, срок, лимит, конкретный покупатель и отключение. |
| Отзывы | Просмотр последних 100 отзывов и удаление. |
| Платежи | Очередь проверки с доступными решениями по конкретному платежу. |
| Статистика | Сводка, периоды 7/30/90 дней, популярные модели, покупатели, способы оплаты и использование промокодов. |
| Настройки | Курс рубля, состояние платёжных методов, баланс покупателя, сохранённые цвета кнопок бота. |

Возвраты, решения по спорным платежам и изменение баланса требуют проверки и отдельного подтверждения. Подтверждение связано с администратором, действует 3 минуты и используется один раз. Stars возвращаются только полностью; остальные ограничения прежнего платёжного контура сохраняются.

Сохранение товара проверяет версию карточки. Если другой администратор, загрузка или покупка изменили товар, устаревшую форму нужно открыть заново. Удаление убирает товар из каталога и корзин, сохраняя оплаченные заказы и доступ к купленным архивам. Метаданные действий записываются в `admin_app_audit` без токенов и содержимого запросов.

## Файлы и развёртывание

Новые фотографии и ZIP хранятся в `admin-media` рядом с SQLite (`/app/data/admin-media` на Railway). Каталог должен находиться на постоянном томе вместе с базой. При переносе или резервном копировании магазина сохраняйте **и SQLite, и `admin-media`**; существующий автоматический SQLite-backup не включает файлы этого каталога.

Фотографии публичны как изображения витрины. ZIP не публикуются в каталоге изображений. После запроса скачивания бот присылает подписанную ссылку сроком 24 часа; сервер заново проверяет право покупки при скачивании. После истечения ссылки можно запросить новую из заказа. При замене архива выдаётся последняя версия, после полного возврата доступ закрывается. Старые архивы с Telegram `file_id` продолжают отправляться прежним способом.

`ADMIN_MINIAPP_ONLY=true` включён по умолчанию при наличии `WEBAPP_URL`: прежние административные команды и кнопки открывают новую админку вместо изменения данных в диалоге. `/start`, оферта, контакты, обработка оплаты и доставка файлов сохраняются. `BOT_ADMIN_ONLY=true` по-прежнему направляет покупателей в витрину. Для установки без Mini App предусмотрена совместимость с прежними командами (`ADMIN_MINIAPP_ONLY=false`).

## Порядок товаров

В карточке товара, в разделе «Основное», задайте «Порядок отображения» и сохраните. Меньше число — выше позиция в каталоге бота и Mini App; допустимы отрицательные целые значения. При одинаковых значениях товары идут по ID. Новые и существующие товары по умолчанию имеют 0. Модификации сортируются внутри основной модели, отдельно от самостоятельных карточек. Порядок применяется перед разбивкой на страницы и к результатам поиска. В списке админки текущий порядок виден рядом с ценой. Для категорий используется прежнее поле порядка в карточке категории.
