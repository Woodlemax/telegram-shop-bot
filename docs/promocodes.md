# Промокоды

Управление доступно администратору в личном чате с ботом:

- `/addpromo КОД скидка [лимит] [дней] [ID категории]` — создать код;
- `/listpromos` — показать активные коды, ID, использованные/доступные применения,
  дату окончания (UTC) и категорию;
- `/deletepromo ID` — отключить код.

Скидка — целое число от 1 до 100. Код содержит 1–32 символа A–Z, 0–9, `_` или
`-`; регистр не важен. Лимит — неотрицательное целое число; 0 или отсутствие
параметра означает без ограничения. Дней — от 0 до 36500; 0 или отсутствие
параметра означает без срока. Категория должна существовать. Чтобы задать
категорию без лимита и срока, укажите 0 в обоих предыдущих параметрах.

Примеры (сами по себе не создают коды):

```text
/addpromo MODEL10 10
/addpromo WEEK20 20 100 7
/addpromo PLANES10 10 0 0 2
```

Первый код даёт 10% на всю корзину. Второй — 20% с лимитом 100 применений и
сроком 7 дней. Третий — 10% только на товары категории 2. ID категорий можно
получить командой `/listcategories`. Дубликат не изменяет уже существующий код;
неверный процент, параметры или отказ хранилища не дают сообщения об успехе.

В Mini App введите код в корзине. После короткой паузы он проверяется на
сервере, и итог обновляется в рублях и Stars; исходная сумма показывается
отдельно. Проверка не создаёт заказ и не использует промокод. Изменение свободной
цены сначала сохраняется, затем пересчитывается скидка. Старые ответы сервера
не заменяют новый код; удаление кода возвращает обычный итог. Ошибка проверки
показывается в корзине, а оформление недоступно до исправления или удаления кода.

Код категории снижает только стоимость товаров этой категории. Например,
200 ₽ в нужной категории + 200 ₽ в другой с 10% скидкой дают 380 ₽. Глобальная
скидка применяется ко всей корзине. Рубли округляются до копеек, Stars — до
целого числа; положительная сумма сохраняет минимум 1 Star.

Если после скидки весь заказ бесплатен, появляется **Получить без оплаты**.
Это выдача без счёта и платёжного списания; использование кода записывается при
выдаче. Скидка 100% на одну категорию не делает бесплатными товары другой
категории. Подписки остаются платными через Stars.

Один покупатель использует каждый код один раз. Пока есть неоплаченный заказ
с этим кодом, второй заказ с ним создать нельзя: оплатите или отмените первый.
Персональные коды доступны только своему владельцу. Неактивные, истёкшие и
исчерпавшие лимит подтверждённых использований коды не принимаются для нового
заказа. Проверка повторяется при оформлении. Уже сохранённые суммы заказа и
продолжение оплаты не пересчитываются при изменении каталога, курса или кода.

`POST /api/cart/promo {"promo":"MODEL10"}` требует Telegram initData и возвращает
итог текущей корзины, исходные суммы, сведения о коде и возможность бесплатного
оформления. Данные не кешируются. Цена, пользователь и состав корзины берутся
с сервера; предварительный расчёт не даёт доступа к файлам.

Проверки: реальные SQLite-базы и фиктивный Telegram для админских команд,
ограничений, категорийных скидок, совпадения расчёта и заказа, выдачи без оплаты,
ошибок и повторной проверки. `node tests/miniapp-promos.cjs` проверяет ввод,
пересчёт, сохранение свободной цены, устаревшие ответы, ошибки, возврат в корзину,
снятие кода и одно нажатие кнопки после потери фокуса. Реальных платежей нет.
